# Affinity Answers – Data Engineer Intern Assignment

Hi! This repository contains my solutions to the three questions for the Data Engineer Intern assignment at Affinity Answers.

### Solutions

- **Question 1 – Python:** A product scraper that accepts a search term and extracts product information from MD Computers.
- **Question 2 – SQL:** Queries for the Rfam database covering taxonomy, DNA sequence lengths, and pagination.
- **Question 3 – Shell Scripting:** A Bash script that downloads company data from a CSV URL and displays company names, locations, and founding years sorted by year.

### How to Run

- **Question 1:** Install the dependencies listed in `requirements.txt` and run the Python script in `question1/`.
- **Question 2:** Open `question2/rfam_queries.sql` in MySQL Workbench and execute the queries against the Rfam database.
- **Question 3:** Run the shell script with the CSV URL as an argument:

```bash
bash question3/company_report.sh "https://raw.githubusercontent.com/datasets/s-and-p-500-companies/refs/heads/main/data/constituents.csv"
```
